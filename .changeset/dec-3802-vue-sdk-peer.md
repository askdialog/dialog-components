Vue's peer `@askdialog/dialog-sdk` is now `^3.4.0` (DEC-3802). Vue 4.3.0 already needed SDK 3.3.0, for `titleParts` as `TitlePart[]` and `productHitDisplay(controller, hit)`, but accepted 3.1 and 3.2. SDK 3.4.0 adds the Arabic, Japanese, Korean, Dutch, Polish and Portuguese search texts. Upgrading from Vue 4.3.0: install SDK 3.4.0 or later with it.
